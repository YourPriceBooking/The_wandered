## 2. Серверні статті та статуси — реалізовано в поточному PR, очікує мерджу

Особливість Next.js 14: при server notFound локалізований UI помилки передається
через клієнтський Flight fallback; у початковому документі перевіряються HTTP 404
та noindex. Вимога читабельного контенту без JS перевіряється для самих статей.
Timeout API обмежений 10 секундами на спробу; Next може повторити lookup при
рендерингу error fallback, тому загальний час помилкової відповіді може бути довшим.

- [x] Серверні H1, текст, автор, дата, головне зображення для всіх восьми шаблонів статей.
- [x] Один request-local lookup для metadata і контенту; без постійного кешування помилок.
- [x] URL статті через URLSearchParams, перевірка &, Unicode і відсутніх полів.
- [x] Timeout, перевірка JSON/запису; відсутність відрізняється від збою сервісу.
- [x] Missing/видалений запис: HTTP 404, noindex, локалізована навігація.
- [x] 5xx, timeout, невідома 409 і некоректна відповідь: серверна помилка, не 404.
- [x] Безпечна серверна обробка редакторського HTML: таблиці, зображення, підписи, цитати, iframe.
- [x] Авторська підказка, лічильник і related articles збережені як клієнтські частини.
- [x] Готовий контент не приховується таймерами; глобальний loading не випереджає визначення статусу.
- [x] Списки більше не повертають рядок err замість даних.
- [x] Production HTTP-тести без JS: success/404/5xx/timeout/санітизація, включно з мовами uk/pl/en.

## Критерій завершення програми

Усі типи статей читаються без JS; 404/5xx коректні; кожен публічний шаблон має
OG/Twitter із доступним зображенням; canonical, мови, архів, schema та sitemap
узгоджені; чотири travel tools працюють; CI захищає реалізацію від регресій.
Search Console й production-продуктивність приймаються за фактичними даними,
без обіцянки конкретних позицій у пошуку.
